# The escalation (template)

Rename the note to something like The staircase. Here you plan the steps from the first omen to the worst. Keep adding as you write.

**The first omen:** the smallest thing that does not fit. Which chapter, and how it can be explained away.

**The second step:** the same again, bigger or closer. What weakens the explanation.

**The pattern:** when the reader realises it follows a rule, and which rule.

**The intrusion:** when the threat gets into what is safe. The home, the body, someone close.

**No one believes:** when the main character asks for help and is dismissed, and by whom.

**The first price:** the first time someone pays. Who, and what it shows about the threat.

**The false calm:** the respite after the loss, when it seems possible to live with. What the main character dares to hope for.

**The truth:** what the main character learns about where the threat comes from, and how it makes things worse.

**The failed escape:** the attempt that goes wrong, and what it reveals.

**The isolation completed:** when the last route to help closes.

**The worst:** the scene the whole book builds towards. Where it happens and what is at stake.

**The echo:** the last chill. What remains when it all seems over.

**Check:** read the steps in order. Is each worse than the one before? Is there respite between them? Swap two steps if they feel equally strong.
