# Checklista för första utkastet

Stäm av när utkastet är klart:

- Kommer brottet tidigt nog?
- Har läsaren mött den skyldige innan avslöjandet?
- Syns varje ledtråd som lösningen bygger på, innan utredaren förstår den?
- Har varje misstänkt ett motiv, ett tillfälle och något att dölja?
- Leder det falska spåret läsaren fel utan att ljuga?
- Går tidslinjen ihop, med alibin som håller eller spricker på rätt ställe?
- Kostar fallet utredaren något?
