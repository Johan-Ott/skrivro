# Det som verkligen hände (mall)

Brottet som det faktiskt gick till, i tidsordning. Läsaren ser det aldrig så här, men du behöver det för att allt ska gå ihop.

- **Före:** det som ledde fram till brottet.
- **Brottet:** tid, plats, hur.
- **Efteråt:** vad den skyldige gjorde för att dölja det.
- **Spåren som blev kvar:** varje ledtråd, och var den finns.
