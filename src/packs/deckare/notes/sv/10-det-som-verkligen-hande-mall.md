# Det som verkligen hände (mall)

Byt namn på anteckningen till fallets namn. Här står brottet som det faktiskt gick till, i tidsordning. Läsaren ser det aldrig så här, men du behöver det för att allt ska gå ihop. Skriv den här först.

**Rötterna:** vad hände för länge sedan som gjorde brottet möjligt? Ett gammalt svek, ett arv, en olycka som tystades ned.

**Utlösaren:** vad hände strax före som gjorde att det inte kunde vänta?

**Dygnet före:** var var offret, den skyldige och varje misstänkt? Skriv klockslag.

**Brottet:** tid, plats och hur. Vad gjorde den skyldige, steg för steg?

**Minuterna efter:** vad gjorde den skyldige för att dölja det? Vad flyttades, tvättades eller togs med?

**Dagarna efter:** hur fortsätter den skyldige att skydda sig medan utredningen pågår?

**Det som gick snett:** vad blev inte som planerat? Ett vittne, ett väder, en sak som glömdes kvar.

**Spåren som blev kvar:** varje spår som brottet lämnade, och var det finns. För över dem till Ledtrådslistan.

**Vem som vet vad:** vem har sett eller hört något, och varför har de inte sagt det?
