# The villain's plan (template)

Rename the note to the name of the plan. This is what the villain does, in order, whether the reader sees it or not. Write it before you write the chase, so the villain always has a move to make.

**The end goal:** what happens if the plan succeeds? Who is hurt, and how?

**The deadline:** when must the plan be carried out, and why then?

**Preparations:** what has the villain already done when the book opens?

**The steps:** write each step with a time and a place. For example: Monday night, the key card is stolen; Wednesday, the guard is replaced; Friday at 6 am, the truck rolls in.

**What the main character sees:** for each step, what trace does it leave, and when do they find it?

**The villain's answers:** when the main character gets closer, what moves does the villain make? Threats, false trails, an attack, an offer?

**Why the villain does not just get rid of the main character:** if they could, why not? They need something the main character knows or has, a death would draw attention, or it has turned personal and they want to win.

**The fallback:** what does the villain do when the first plan cracks?

**The crack:** the point where the plan is vulnerable, and which the main character finally finds.

**What the reader knows first:** which steps do you show from the villain's point of view, to build suspense?
