# Skurken (mall)

Byt namn på anteckningen till personens namn.

**Målet:** vad vill hen uppnå? Skriv det på en mening, utan att använda ordet ond.

**Varför hen tror att hen har rätt:** ur hens perspektiv är hen hjälten. Vilken orättvisa, förlust eller övertygelse bär hen på?

**Resurserna:** pengar, folk, kunskap, tillgång, tid. Vad har hen som huvudpersonen saknar?

**Metoden:** hur arbetar hen? Med våld, lögner, tekniken, lagen, andras rädsla?

**Varför hen är farlig just för huvudpersonen:** vad vet hen om hen, eller vad kan hen ta ifrån hen?

**Spegeln:** på vilket sätt liknar skurken huvudpersonen? Ett val som hade kunnat gå åt andra hållet.

**Första gången läsaren ser hen:** hen själv, eller bara hens verk? Låt det vara ett drag som visar förmåga och kontroll, inte bara grymhet.

**Masken:** om identiteten ska vara hemlig, vem tror läsaren att hen är? Var dyker hen upp utan att avslöjas?

**Hur hen svarar på motstånd:** när planen stöter på problem, blir hen mer försiktig, mer våldsam, eller mer personlig?

**Svagheten:** stolthet, en person hen bryr sig om, ett behov av att bli sedd. Den som huvudpersonen till sist kan använda.

**Gränsen hen går över:** ögonblicket där läsaren förstår att hen är beredd till vad som helst.

**Slutet:** hur förlorar hen, och vad säger det om hen?
