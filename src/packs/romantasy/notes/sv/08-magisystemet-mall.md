# Magisystemet (mall)

**Vem har magin:** och vem har den inte.

**Regler:** vad den kan och inte kan göra.

**Priset:** vad varje användning kostar.

**Gränsen:** det som aldrig går, hur mycket man än betalar.

**Hur den knyter an till kärleken:** ett band, ett arv eller en förbannelse som rör dem båda.
