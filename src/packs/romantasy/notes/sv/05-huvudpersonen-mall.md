# Huvudpersonen (mall)

Byt namn på anteckningen till personens namn.

**Vill:** vad hen jagar när boken börjar.

**Behöver:** det hen måste lära sig för att bli hel.

**Såret:** det som gör hen rädd för att lita på någon.

**Förmågan:** magi, arv eller färdighet, och vad den kostar.

**Hemligheten:** det hen inte vill att kärleksintresset ska veta.

**Vad hen riskerar:** i världen, och mellan dem.
